Read the patient-doctor transcript and extract the differential diagnoses (possible
conditions considered, each with a valid ICD-10-CM code) and the assessment (the primary
or working diagnoses, each with its ICD-10-CM code).

<differentials>

Extract the differential diagnoses discussed or implied.
For each, determine:
  - Diagnosis name (with laterality, body site, acuity)
  - ICD-10-CM code
Sort by likelihood (most likely first) and report only the 3 most relevant
differentials. If fewer than 3 were discussed, report only those.
Make each diagnosis as specific as the transcript supports: laterality, body site, and
encounter type (initial encounter, follow-up, or sequela).

If no differential diagnoses were discussed, return an empty list.

</differentials>

<assessment>

Extract the primary or working diagnoses — the condition(s) the clinician is actively
treating or working up, as opposed to other possibilities merely considered (those go in
<differentials>).
For each, determine:
  - Diagnosis name (with laterality, body site, acuity)
  - ICD-10-CM code
Sort by likelihood (most likely first) and report only the 3 most relevant. If fewer
than 3 were discussed, report only those.
Make each diagnosis as specific as the transcript supports: laterality, body site, and
encounter type (initial encounter, follow-up, or sequela).

Every encounter MUST have at least one primary diagnosis.

</assessment>
